- **Scheduled runs keep already-shared notes current, after the privacy check** (`engine/scout/kb/lint_privacy.py`, `phases/core/privacy.md`). Since #569 the commit hook refused every scheduled run's added or reworded line in a note with an effective share, so shared project pages went stale and the review queue filled with edits nothing applied. With the new `privacy.shared_edits: checked` (the default), such a line passes when it names or links no private note (by slug, `name:`, `title:` or alias), no note shared with fewer people than this one, and quotes no note shared with you. HTML entities and markup (`S&#97;mmy`, `Sa**mm**y`) are decoded first, and a `%%privacy:allow%%` marker allows none of a run's lines there, as for an outbound send. **The hook does not read what a private note says, nor email, Slack or meetings:** a run that restates a private fact without naming its note passes, and so does anything from unshared notes or connectors. The phase rule tells runs to write only what came from that note, notes shared with the same people, or sources those people were in. Still refused in a scheduled run, unchanged: sharing a note more widely, setting or changing its `federation_scope` (narrowing too), adding a marker, making a private note normal, editing the `privacy:` block, and any change to a non-note file in a share (`.csv`, `.xlsx`, …). New: a shared note whose staged text isn't UTF-8 keeps the old freeze.
- **The nightly KB pass may rebuild a shared project page** (`engine/scout/kb/structure.py`, `phases/modes/kb-deep-work.md`). Under `checked`, `kb structure --next` picks a page with an effective share for a full rebuild only when all of these hold: every other note in its folder is shared with at least the page's readers (none private, local-only, unshared or shared more narrowly), the page declares no `federation_scope` of its own (its archive copy would set one), and no note the rebuild could write (new subfolder notes, new source notes) would be shared with someone the page isn't. Otherwise an over-budget page falls back to trim-only, as before, and any other is skipped. A loose file with a share still stays where it is. The mode is the strictest of the committed, staged and working-tree config, as in the hook.
- **The privacy checks read `.MD` notes too** (`engine/scout/kb/lint_config.py`): the privacy scope matched `.md` case-sensitively, so a note named `Plan.MD` under `knowledge-base/` skipped the private-link and widening checks.
