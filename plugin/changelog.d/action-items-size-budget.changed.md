- The stale-item archive now covers `action-items/backlog.md`. Moving a task between the daily file and the backlog keeps its 60-day clock, and backlog tasks nobody touches age out like any other, at most 25 a day, oldest first. Rebuilding the ledger cache restarts the clocks of tasks that are only in the backlog, so a rebuild can't archive them all at once. A daily file with no open tasks (a truncated rewrite) no longer restarts every item's clock. `archive-stale` now takes the vault's session lock, except with `--dry-run`.
- kb-lint gives `action-items/backlog.md` no size budget and keeps it out of the dreaming shrink pass, so a growing backlog never pushes a run to drop tasks to commit. `scoutctl bootstrap doctor` warns when a vault's own `kb_lint` lists bring a budget back.
- `phases/core/action-items.md` gains *The Backlog and the Budget*: the daily file holds today's work and the backlog holds the rest. Runs re-read both files after `fit` writes and commit the backlog and notes it wrote together with the daily file. The `check-size` gate runs before each commit. The count-guard and dropoff audit now compare unique open tags across the daily file and the backlog, using the committed backlog for the prior day. Each item gets one line of up to 300 characters plus at most one prose sub-bullet, and ✅ Recently Completed keeps 3 days, down from 7.
