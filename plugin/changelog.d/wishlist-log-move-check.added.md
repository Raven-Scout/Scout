- **A wishlist log that leaves a card lands verbatim in its progress note** (`engine/scout/wishlist/log_move.py`). The new `scoutctl wishlist check-log-move --data-dir <vault> <paths>` holds the wishlist phase's *the item file is a card, not a log* rule at commit, and the phase's commit step (`phases/modes/wishlist.md`, Step 3e) runs it with the paths it will commit. For each card in `docs/wishlist/` changed since the last commit, every dated line it lost (a line under a dated heading, a line that starts with a date, or a ticked sub-task with a date) must be in `docs/wishlist/progress/<item file name>` as the commit will hold it: byte for byte, in the card's order. New entries may sit above the moved log, and lines the note already held count. Exit 1 names the item and the first missing line; exit 2 means it couldn't check (not a git repository, or a file that isn't UTF-8).
