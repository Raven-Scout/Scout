- **The CHANGELOGs no longer have a `## [Unreleased]` section** (`CHANGELOG.md`, `changelog.d/README.md`, `engine/scout/scripts/changelog.py`). It was kept only for PRs opened before changelog fragments, and those have merged. `python -m scout.scripts.changelog check` (the `contract` job, on every run) and `scripts/release.sh prepare` now refuse a CHANGELOG that has the heading again, since its entries would never be released, and `prepare` assembles a release from the `changelog.d/` fragments alone.
