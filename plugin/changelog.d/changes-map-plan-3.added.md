- **The Changes tab replaces proposals in the run instructions.** Scheduled runs no longer write new entries to `dreaming-proposals.md`. A large, structural or uncertain change to Scout's own instructions or scripts goes in directly, like any other, and is tested and undoable from the app's Changes tab. A change to what Scout may do on its own still waits in `governance-pending/` for the owner's OK in the Changes tab; if the runtime blocks a direct commit, Scout files the same pending item with `governance: false`, and a later run applies it as an ordinary change. Dreaming still applies any proposal already in `dreaming-proposals.md` that was approved or has ripened.
  - A new vault no longer gets an empty `dreaming-proposals.md`. An existing vault's file is left exactly as it is.
