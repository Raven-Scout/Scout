- **State, lock and log writes never follow a planted link** (`engine/scout/safe_write.py`). A scheduled run could put a symlink where a later owner command or the schedule tick wrote a temp file, a lock or a log, such as `.scout-state/delegate-mirrors.json.tmp`. That write then went through the link into a file the run's sandbox protects, such as the plugin's hooks, a secrets file or a git hook.
  - **Whole-file writes.** The state, cache and config files, the vault's `.gitignore` and the files `bootstrap` installs now use a new temp file beside the target with a random name, opened so that nothing already at that name is used, then synced and renamed into place.
  - **Logs and locks.** The schedule tick, heartbeat, self-update, health notifier and delegate mirror refuse a log or lock file that is a symlink, a hard link or not a plain file, and write nothing. A rotated log still works.
