- **The raw-read gate denies the shell reads that got past it** (`engine/scout/kb/raw_read.py`, `hooks/hooks.json`): an audit found many raw shell reads into `knowledge-base/` getting past it. A run is now also denied a read through a variable or loop holding a KB path (`f=knowledge-base/…; wc -c $f`, `for f in $(scoutctl kb files)`, `while read f`), one that `xargs` feeds with KB paths, a read after `do` or `then`, an input redirection from a KB path, a command substitution that runs a path-printing `scoutctl kb` (`cat $(scoutctl kb files)`), a quoted program (`bash -c`, `eval`), a quoted or brace-split path, `env -C`, `stat`, `du`, `sort`, `diff` and other readers, `git show|diff|log -p` past git's own options (`--no-pager`, `-c k=v`), and a recursive read that reaches a KB note: from the vault or above or a KB folder's parent (`rg x`, `grep -r x action-items`, `git grep x`, `find . -exec cat`), with `~` and `$VAR` put in from the run's environment. A recursive search is judged on the shell's own word split, so a quoted `|` or `;` in a pattern (`rg -n "TODO|FIXME" scripts/`) doesn't count, and neither does a search a file filter keeps out of the KB (`--include=*.py`, `-g '*.py'`, `-g 'docs/*.md'`, `rg -t py`; a filter that could still match a note, like `-g '*people*'` or `*.{md,txt}`, bounds nothing), one `xargs` hands its files, or a summary like `du -sh`. A glob over daily files (`ls action-items/*.md`) is allowed; one that spells a KB folder (`know*/x.md`) is denied, and so is a search from a folder the gate can't follow (`cd "$X" && rg x action-items`, `rg x "$(pwd)"`). Prefixes by absolute path (`/usr/bin/env`, `/usr/bin/xargs`) count. Known gap, which main never denied either: `xargs` fed by a command that prints no KB path (`ls | xargs rg x`). The deny message points at `kb read --lines` and `kb stat`. Every earlier deny stands, and piping `scoutctl kb` output stays allowed.
