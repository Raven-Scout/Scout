- **Pluggable KB backend interface and canonical JSONL property-graph export** (`engine/scout/kb/backend.py`, `engine/scout/kb/export_jsonl.py`). Adds the domain-level `KBBackend` Protocol with `FilesBackend` as the zero-dependency reference implementation (`entities`, `entity`, `related`, `neighbors`, `paths`, `backlinks`, `link_gaps`, `search`, `resolve`, `name_lookup`, `stats`, `validate`, `capabilities`), plus `scoutctl kb export --format jsonl` to emit a privacy-filtered property graph joining ontology relationships with resolved body `[[wikilinks]]`.
