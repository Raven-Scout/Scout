- **`kb lint` now checks a file replaced by a symlink, and reports a symlink that points outside its own share** (`engine/scout/kb/git_io.py`, `engine/scout/kb/lint_privacy.py`; #606). A type change (git status `T`, a regular file replaced by a symlink or the reverse) was left out of the staged-file list, so no check looked at it. It is now listed and checked like any modified file. A staged symlink is also checked against its target: a shared link that points at a private note, a file no share covers or one shared with fewer people, and any link that uploads but points at a local-only path or outside the vault, is reported. A scheduled run's commit is blocked (`privacy-widening`); the owner gets a warning (the new `link-leaves-scope` check). A link inside a local-only path stays home, so it may point anywhere.
- **The size and line lint now treats `x.MD` as a note** (`engine/scout/kb/lint_config.py`; #605). The privacy checks, the classifier, repo sync and the Agnes mirror already ignored the case of `.md`; the size, long-line and diary checks still skipped a note whose suffix was upper case.
- **`cat <&3` is no longer refused as a detached command in a scheduled run** (`engine/scout/kb/live_run.py`; #618). The run gate read the `&` of a descriptor duplicate (`<&3`) as a background `&`. `cmd &` and `cmd & disown` are still refused.
