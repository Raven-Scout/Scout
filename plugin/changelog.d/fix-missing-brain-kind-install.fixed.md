- `scoutctl bootstrap upgrade` installs a brain file new to the vault. Since v0.18.22 an upgrade recorded `RESPOND.md` as installed without writing it, so Telegram replies ran without their brain; the next upgrade now writes it, and repairs a vault an earlier upgrade left without it. `bootstrap doctor` warns (yellow) when any brain file (`SKILL.md`, `DREAMING.md`, `RESEARCH.md`, `RESPOND.md`) is missing, and says to run `/scout-update`.
