- **Research runs now work the Lab.** A run answers owner comments first, then runs due experiments (attached or detached) and collects finished ones, then advances one or two threads, then proposes new threads; the wrap reports what moved. Ideas left in the inbox become comments on a matching thread or wait for a research run to propose them.
- **The heartbeat starts research runs from the Lab's state.** It no longer uses the old research queue to decide when a research run fires.
- **Experiments can run detached for hours.** A supervisor that outlives the run keeps them going, under the owner's switches `lab.detached_max_hours` and `lab.max_detached`. Experiments can also read Hugging Face weights (safetensors only, pinned to a commit) from an owner-side read-only cache (`lab.weights_max_bytes`), use the GPU when `lab.gpu` is on, and declare a disk budget up to `lab.max_total_bytes` with a free-disk floor (`lab.disk_free_floor_bytes`). All of these are off by default.
- **The run broker's commit refuses any file over 10 MiB under the lab**, and `checkpoints/` folders are never committed.
