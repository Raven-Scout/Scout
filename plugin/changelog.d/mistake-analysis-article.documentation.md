- **The project site has a long-form analysis of Scout's own mistake log** (`docs/writing/mistake-log-analysis.html`). It classifies all 297 entries logged from April to November 2026 against a fixed rubric: root causes, who caught each mistake, how many fixes held, the silent failures, and the parts that don't flatter the project.
