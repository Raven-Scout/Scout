- `scoutctl action-items fit` keeps the daily action-items file to its budget, with no model involved and nothing deleted. It moves 🅿️ Parked, 🟢 Watching and 🟡 tasks not due within 14 days to `action-items/backlog.md`, and moves backlog 🟡 tasks back when they come due. Past 80 open tasks it moves the bottom of 🟡 to the backlog. Prose sub-bullets past the first move to each task's context note, and ✅ Recently Completed keeps 3 days. `materialize` runs it once a day. Under `action_items.fit: report` (the default for this release) it writes nothing and records what it would do in `.scout-logs/action-items-fit.json`; set `apply` to let it write.
- `scoutctl action-items check-size` checks the daily file against `action_items.budget` in `scout-config.yaml`: a target of 50 KB and 80 open tasks, and a hard limit of 60 KB and 100. Briefings and consolidations run it before committing. Past the target it is a warning plus a 🪵 Run notes line, and `scoutctl bootstrap doctor` warns past the hard limit. Neither ever fails a run.
