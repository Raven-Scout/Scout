- **Text uses nine type roles instead of 26 point sizes** (UI audit #104). Every label, title and line picks a role (`DS.font(.caption)`, `.body`, `.headline`…), and two roles are new: `micro` (9 pt, for badges) and `hero` (22 pt, for large figures and sheet titles). Most text moves by half a point or less. Section titles that were 14 or 16 pt are now 15 pt, and the few 20 and 24 pt titles are 18 and 22 pt. A guard test fails on any new size-based font call.
- **A colour means one thing** (UI audit #107). The urgent red now marks only Urgent: the topic board's "Mine" and the Sessions "needs you" state use a new cobalt "waiting on you" colour, and the Knowledge Base's Issues notes get their own lime, each clearly apart from its neighbours. The on-battery banner, run-feedback errors and the run detail's status dot, tool names, file sections and log highlights use the design-system colours instead of the system ones. A guard test keeps the red and the system named colours out.
- **Monospace is for data, not sentences** (UI audit #108). The Now strip's run lines, the Upcoming strip's subtitles, the usage card's labels and messages, the heatmap legend, the connector banner and about 15 other lines are set in the regular sans voice. IDs, paths, commands, logs and times stay monospace.
- **Every button outside menus and alerts uses a design-system style.** Add item, custom snooze, the Knowledge Base's rename and new-note sheets, the Doctor and Diagnostics windows, run feedback, the run and session detail actions, the diff and log toolbars and the PR-check problems popover all moved off system push buttons, and each sheet's default action is the filled primary button. Settings actions that read as plain text (Run protection, delegate copies, the engine update, Health's Mark reviewed) are buttons now; turning write protection off is red. Menus and alerts keep the system buttons.
