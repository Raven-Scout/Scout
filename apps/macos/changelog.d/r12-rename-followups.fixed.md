- **New notes follow the rename rules** (`Scout/KnowledgeBase/KnowledgeBaseFileWriter.swift`, `Views/KnowledgeBaseView.swift`). A new note named `acme.com` is now `acme.com.md`; before, it got no `.md` and didn't show up. Names with `# | [ ] ^`, or starting with a dot, are refused for new and renamed notes, with the reason shown as you type.
- **The Rename sheet warns when the note's own links won't be updated** (`Scout/KnowledgeBase/Views/KBEditorView.swift`). That happens while the note has unsaved edits. A failed commit's message also now ends its sentence before "Edit ▸ Undo".
