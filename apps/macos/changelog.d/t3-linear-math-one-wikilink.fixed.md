- **Unclosed math can't stall a card.** Cards clean up `\(…\)`, `\[…\]` and `$$…$$` math with a linear scan. The old regexes rescanned the line from every opener that never closed, so 5,000 unclosed `\(` took a third of a second, and longer on accented or emoji text. Every replacement is also made in one pass now, not by copying the whole text once per match. The output is unchanged.
- **One rule for what is a wikilink.** Inline text, the Knowledge Base's links and backlinks, rename's link counts, a task's trailing link chips and its `Refs:` line now all use the same `[[target|alias]]` rule. Neither part may hold `[` or a line break. Before, only inline text refused those, so a note could list a backlink that never showed as a link. The table form `[[target\|alias]]` now names the right target in task chips and `Refs:` too.
