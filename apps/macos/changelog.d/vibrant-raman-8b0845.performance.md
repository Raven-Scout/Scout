- A usage refresh, a run ledger re-read or an engine check no longer redraws the whole app. Each part of the window now follows only what it shows: the usage card and the status bar's cost follow the usage summary, the run-health banner follows the run ledger, and the sidebar's badges and dots, the setup screen and Settings change only when a badge, a dot or the engine's setup state actually changes. Before, any of these refreshes redrew the Control Center, the sidebar, the menu-bar panel and the Settings window together.
