- **Action Items works from the keyboard** (`Scout/ActionItems/ActionItemsKeyboard.swift`, UI audit #50). In the List, ↑ ↓ Home End move a highlighted current card, Return or Space opens and closes it, ⌘↵ marks it done and Esc lets go. A click on a card makes it current. Right-clicking a card offers Mark Done or Reopen, Snooze, Expand or Collapse, Copy and Copy As; the writes are off while the engine check fails, like the card's buttons.
- **Schedules rows answer the arrow keys** (`Scout/Schedules/SchedulesMasterTable.swift`, UI audit #57). In the Table and Cards views, ↑ ↓ Home End move the selected schedule and scroll it into view.
- **Knowledge Base: find in a note, and a tree you can drive from the keyboard** (`Scout/KnowledgeBase/Views/KBFind.swift`, `KBTreeView.swift`, UI audit #77). ⌘F finds in the open note: Rich and Source get the system find bar, and Read (the web reader) gets a find bar with ⌘G and ⇧⌘G. ⇧⌘F searches every note, as ⌘F does when no note is open. In the tree, ↑ ↓ Home End move and open notes, → opens a folder and steps into it, ← closes it or steps out, and Return toggles a folder. Source mode is now a plain text view of its own, since `TextEditor` has no find bar on macOS.
