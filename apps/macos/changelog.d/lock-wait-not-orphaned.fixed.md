- A run queued behind another run now shows as "Waiting for another run" instead of "Didn't finish". A run waits up to 30 minutes for the run before it to end, and the app used to count that wait against the run's own time limit. A consolidation queued behind a long dreaming run was marked "Didn't finish" after 20 minutes of waiting. The app now gives the wait in full first, then the run's usual time limit, for every kind of run. This includes Telegram replies, whose limit is now 45 minutes after the wait.
