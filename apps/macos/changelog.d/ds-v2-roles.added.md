- **The brand fonts ship inside the app** (`Scout/Resources/Fonts/`, `Scout/Utilities/DesignSystem.swift`; UI audit #106). Newsreader (16 pt optical cut) for the reading voice and JetBrains Mono for data, each in the three weights the app draws, with their SIL Open Font License texts beside them. They are registered for the app's own process at first use, and nothing is fetched at run time. Before, they only showed on a Mac that had them installed, so most people saw New York and SF Mono.
- **A quiet button role, `.dsQuiet`** (`Scout/Utilities/DSButtonStyle.swift`): grey text, no chrome, one step darker on hover. Dismiss, Cancel, Copy details, Reload and the Now strip's Run now use it, so low-key actions no longer look like plain text or like links.
- **A design-system text field, `.dsField()`** (`Scout/Utilities/DSField.swift`). Settings and onboarding fields now draw a keyboard focus ring, a disabled look that matches disabled buttons, and an error outline.
