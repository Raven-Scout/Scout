- **A long run that is still working no longer shows "Didn't finish"** (`Scout/Services/SessionLogService.swift`). A run with no finish line used to be marked orphaned once it was older than its type's cutoff, counted from its start. Consolidation's cutoff is 20 minutes, so a healthy 23-minute consolidation showed "Didn't finish" (and could send a "stopped without finishing" notification) while it was still working. The cutoff now counts from the run's last sign of life, its log's modification time, so a run whose log goes quiet past the cutoff still shows "Didn't finish". On a vault linked to Agnes, the runner's lease keepalive writes a log line about every five minutes, so a live run stays "Running". On an unlinked vault, nothing writes the log while Claude works, so a long run there can still show "Didn't finish". That is never sooner than before. The once-a-minute sweep and the file watcher both read the log's modification time.
