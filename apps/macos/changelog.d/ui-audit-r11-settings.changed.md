- **Settings is one window, in tabs** (UI audit R11, #10, #82). Settings was both a sidebar page and the ⌘, window, and one scroll about nine screens tall. It is now only the ⌘, window, split into General, Engine, Runs, Action Items, Advanced and Updates. The sidebar's Settings row opens it, still showing the update count and the attention mark, and every "Open Settings" button and link opens it on the right tab. The Go menu runs ⌘1–⌘8; Settings is ⌘,.
- **Folder and program paths are chosen, not typed** (#82). The Scout folder, the Proposals, Wishlist and Research folders and the `claude` program each have Choose… and Use Default, and a path that no longer works says why. A path can no longer be typed in relative form, which Scout either ignored (the Scout folder) or read from the wrong place. The `claude` program is stored as a full path. A chosen Scout folder says when it has no `scout-config.yaml`, or when scheduled runs still use another folder; Scout never re-points scheduled runs by itself.
- **One word for the vault: "Scout folder"**, as in the glossary, across Settings, setup, health and error messages. The Model card says "schedule" instead of "slot", and the Control Center's next-run line reads "Starts in 3 hours" (or "Due now") instead of "· dispatcher armed".
- **The Glossary, Doctor and Export Diagnostics windows are listed once**, in the Help menu, no longer in the Window menu too.
