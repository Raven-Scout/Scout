- **No more raw markup in five places** (UI audit T3). A Research or Wishlist title written in YAML quotes no longer shows its escapes (`\"`), and Proposals titles read their quotes the same way. A `**` that pairs with nothing is now found wherever it is, not only when it is the last one, so Research cards stop showing a literal `**`. The run detail's fallback log tail, the Knowledge Base's "Linked from" snippets and card titles show plain text, with no `**`, backticks or table pipes. Health, problem banners and Settings help show the engine's commands in monospace instead of in backticks. The new `PlainText` helper does both, and it never makes a link. A guard test (`RawMarkupGuardTests`) keeps those places routed through it and fails on any "(s)" plural in the app's own strings.
- **The diagnostics export counts in real plurals** ("1 error, 2 warnings"), not "error(s)".
