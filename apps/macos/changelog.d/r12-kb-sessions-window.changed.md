- **The main window can be narrower: 1070 × 640, down from 1100 × 640** (`Scout/Shell/MainWindowSize.swift`, `ScoutApp.swift`; UI audit #8/#98). 1070 pt is the narrowest width at which every page still lays out with the sidebar open. The Sessions header beside a selected session sets the limit. The layout tests now read the same constant, so they check the size the window allows. With a note and its Links/Graph panel open near that width, the Knowledge Base tree narrows (never below 200 pt) so the editor keeps its 380 pt.
